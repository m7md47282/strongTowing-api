## Overview

The payment system handles all financial transactions between clients and the company, tracks driver commissions, manages cash collections, and processes bi-weekly payroll.

### Key Principles
- **Client Payment**: Client pays the company for the job (full job cost)
- **Driver Commission**: Driver earns a percentage of job cost (set by admin in settings)
- **Cash Handling**: When client pays cash, driver collects and keeps it, but amount is deducted from driver's bi-weekly payroll
- **Bi-Weekly Payroll**: Driver commissions calculated and paid every 2 weeks

## Payment Flow

### Payment Flow Diagram

```
Client Payment → Company
     ↓
Payment Method Selected:
  ├─ Card Payment → Company receives payment → Driver gets commission in payroll
  ├─ Payment Link → Company receives payment → Driver gets commission in payroll
  └─ Cash Payment → Driver collects cash → Driver keeps cash → Cash deducted from payroll
```

### Detailed Flow

#### Scenario 1: Card Payment
1. Client pays $150 via card (dispatcher processes)
2. Company receives $150
3. Driver commission calculated: $150 × 30% = $45
4. $45 added to driver's bi-weekly payroll
5. Driver receives $45 in payroll

#### Scenario 2: Payment Link
1. Dispatcher generates payment link
2. Client pays $150 via payment link
3. Company receives $150
4. Driver commission calculated: $150 × 30% = $45
5. $45 added to driver's bi-weekly payroll
6. Driver receives $45 in payroll

#### Scenario 3: Cash Payment
1. Client gives $150 cash to driver
2. Driver collects and keeps $150 cash
3. Driver commission calculated: $150 × 30% = $45
4. Cash deduction: $150 deducted from driver's payroll
5. Driver's net for this job: $45 - $150 = -$105 (deducted from other earnings)
6. Driver effectively received: $150 cash (kept) - $105 payroll deduction = $45 net

### Example: Bi-Weekly Payroll Calculation

**Driver has 10 jobs in 2-week period:**
- 5 jobs paid by card: $150 each = $750 total
- 3 jobs paid by payment link: $200 each = $600 total
- 2 jobs paid by cash: $150 each = $300 total

**Calculations:**
- Total job revenue: $1,650
- Commission (30%): $1,650 × 0.30 = $495
- Cash collected: $300 (driver kept this cash)
- Net payroll: $495 - $300 = $195

**Driver receives:**
- $195 in payroll (bank transfer/direct deposit)
- $300 cash (already collected)
- **Total driver earnings: $195 + $300 = $495 (30% of $1,650)**

## Payment Methods

### 1. Card Payment
- **Processed by**: Dispatcher
- **Payment Gateway**: Stripe
- **Features**:
  - Save customer cards for future use
  - Process payment immediately
  - Receipt generation
  - Transaction tracking

### 2. Payment Link
- **Generated by**: Dispatcher
- **Payment Gateway**: Stripe Checkout
- **Features**:
  - Unique payment link per job
  - Link expiration (default 7 days, configurable 1-30 days)
  - Email/SMS sending capability
  - Public payment page (no login required)
  - Payment status tracking

### 3. Cash Payment
- **Collected by**: Driver
- **Features**:
  - Driver collects cash from client
  - Driver keeps the cash
  - Amount deducted from driver's bi-weekly payroll
  - Cash collection confirmation by dispatcher
  - Cash collection tracking

## Driver Commission & Payroll

### Commission Settings
- **Set by**: Admin in Settings page (`/admin/settings`)
- **Access**: SuperAdmin only
- **Setting**: Driver Commission Percentage (0-100%)
- **Default**: 30%
- **Applies to**: All drivers (same percentage for all)

### Commission Calculation
```
Driver Commission = Job Cost × (Commission Percentage / 100)
```

**Example:**
- Job Cost: $150
- Commission Percentage: 30%
- Driver Commission: $150 × 0.30 = $45

### Payroll Period
- **Type**: Bi-weekly (every 2 weeks)
- **Fixed periods**: 
  - Period 1: Jan 1-14
  - Period 2: Jan 15-28
  - Period 3: Jan 29 - Feb 11
  - etc.

### Payroll Calculation
```
Gross Commission = Sum of (All Job Costs in Period) × (Commission % / 100)
Cash Collected = Sum of (All Cash Payments Collected in Period)
Net Pay = Gross Commission - Cash Collected
```

### Payroll Status Flow
```
Draft → Finalized → Paid
```

## Database Schema

### SystemSettings Table
```sql
CREATE TABLE SystemSettings (
  Id INT PRIMARY KEY IDENTITY(1,1),
  DriverCommissionPercentage DECIMAL(5,2) NOT NULL DEFAULT 30.00,
  PayPeriodType NVARCHAR(20) NOT NULL DEFAULT 'BiWeekly',
  StripePublicKey NVARCHAR(255),
  StripeSecretKey NVARCHAR(255), -- Encrypted
  StripeEnabled BIT NOT NULL DEFAULT 0,
  UpdatedAt DATETIME2 NOT NULL,
  UpdatedBy NVARCHAR(450) NOT NULL -- Admin User ID
);
```

### Payment Table
```sql
CREATE TABLE Payments (
  Id INT PRIMARY KEY IDENTITY(1,1),
  JobId INT NOT NULL FOREIGN KEY REFERENCES Jobs(Id),
  Amount DECIMAL(10,2) NOT NULL,
  PaymentMethod NVARCHAR(20) NOT NULL, -- 'Card', 'PaymentLink', 'Cash'
  PaymentStatus NVARCHAR(20) NOT NULL, -- 'Pending', 'Paid', 'Failed', 'Refunded'
  
  -- Stripe fields
  StripePaymentIntentId NVARCHAR(255),
  StripeChargeId NVARCHAR(255),
  CardLast4 NVARCHAR(4),
  CardBrand NVARCHAR(50),
  
  -- Payment link
  PaymentLinkId INT FOREIGN KEY REFERENCES PaymentLinks(Id),
  
  -- Cash collection
  CashCollectedBy NVARCHAR(450), -- Driver User ID
  CashCollectedAt DATETIME2,
  
  -- Processing
  ProcessedBy NVARCHAR(450), -- Dispatcher User ID
  ProcessedAt DATETIME2,
  TransactionId NVARCHAR(255),
  
  -- Refund
  RefundedAt DATETIME2,
  RefundReason NVARCHAR(500),
  RefundAmount DECIMAL(10,2),
  
  CreatedAt DATETIME2 NOT NULL DEFAULT GETUTCDATE()
);
```

### SavedCards Table
```sql
CREATE TABLE SavedCards (
  Id INT PRIMARY KEY IDENTITY(1,1),
  ClientId NVARCHAR(450) NOT NULL FOREIGN KEY REFERENCES AspNetUsers(Id),

  Last4 NVARCHAR(4) NOT NULL,
```

### CashCollections Table
```sql
CREATE TABLE CashCollections (
  Id INT PRIMARY KEY IDENTITY(1,1),

  DriverId NVARCHAR(450) NOT NULL FOREIGN KEY REFERENCES AspNetUsers(Id),
  Amount DECIMAL(10,2) NOT NULL,
  CollectedAt DATETIME2 NOT NULL,
  ConfirmedBy NVARCHAR(450), -- Dispatcher User ID
  ConfirmedAt DATETIME2,
  Notes NVARCHAR(1000),
  Status NVARCHAR(20) NOT NULL DEFAULT 'Pending', -- 'Pending', 'Confirmed'
  CreatedAt DATETIME2 NOT NULL DEFAULT GETUTCDATE()
);
```

### DriverPayroll Table
```sql
CREATE TABLE DriverPayroll (
  Id INT PRIMARY KEY IDENTITY(1,1),
  DriverId NVARCHAR(450) NOT NULL FOREIGN KEY REFERENCES AspNetUsers(Id),
  PayPeriodStart DATE NOT NULL,
  PayPeriodEnd DATE NOT NULL,

  GrossEarnings DECIMAL(10,2) NOT NULL DEFAULT 0,
  CashCollections DECIMAL(10,2) NOT NULL DEFAULT 0,
  NetPay DECIMAL(10,2) NOT NULL DEFAULT 0,
  
  -- Status
  Status NVARCHAR(20) NOT NULL DEFAULT 'Draft', -- 'Draft', 'Finalized', 'Paid'
  
  -- Metadata
  FinalizedAt DATETIME2,
  FinalizedBy NVARCHAR(450), -- Admin User ID
  PaidAt DATETIME2,
  PaidBy NVARCHAR(450), -- Admin User ID
  Notes NVARCHAR(1000),
  
  CreatedAt DATETIME2 NOT NULL DEFAULT GETUTCDATE(),
  UpdatedAt DATETIME2 NOT NULL DEFAULT GETUTCDATE()

```

## API Endpoints

### Settings Endpoints
- `GET /api/settings` - Get system settings
- `PUT /api/settings` - Update settings (Admin only)

### Payment Endpoints
- `POST /api/payments` - Process payment
- `GET /api/payments` - Get all payments (with filters)
  - Query params: `paymentMethod`, `status`, `startDate`, `endDate`, `driverId`, `page`, `pageSize`
- `GET /api/payments/{paymentId}` - Get payment details
- `GET /api/payments/job/{jobId}` - Get payment for job
- `GET /api/payments/statistics` - Get payment statistics
- `POST /api/payments/card` - Process card payment with Stripe
- `POST /api/payments/cash/collect` - Mark cash collected
- `POST /api/payments/{paymentId}/refund` - Process refund
- `GET /api/payments/export` - Export payments (CSV/Excel)

### Stripe Endpoints
- `POST /api/stripe/create-payment-intent` - Create payment intent
- `POST /api/stripe/confirm-payment` - Confirm payment
- `POST /api/stripe/save-card` - Save customer card
- `GET /api/stripe/cards/{clientId}` - Get saved cards
- `DELETE /api/stripe/cards/{cardId}` - Remove card
- `POST /api/stripe/create-checkout-session` - Create checkout session

### Payment Link Endpoints (Existing)
- `POST /api/payments/links` - Create payment link
- `GET /api/payments/links/job/{jobId}` - Get payment links for job
- `GET /api/payments/links/{linkToken}` - Get payment link details
- `POST /api/payments/links/{linkToken}/process` - Process payment via link
- `POST /api/payments/links/{linkToken}/clear` - Clear payment link

### Payroll Endpoints
- `GET /api/payroll/periods` - Get all pay periods
- `GET /api/payroll/period/{periodId}` - Get payroll for specific period
- `GET /api/payroll/driver/{driverId}` - Get driver's payroll history
- `GET /api/payroll/driver/{driverId}/current` - Get current period payroll
- `POST /api/payroll/calculate` - Calculate payroll for period
- `POST /api/payroll/{payrollId}/finalize` - Finalize payroll (Admin only)
- `POST /api/payroll/{payrollId}/mark-paid` - Mark payroll as paid (Admin only)
- `GET /api/payroll/{payrollId}/report` - Generate payroll report (PDF/Excel)

### Financial Report Endpoints
- `GET /api/reports/financial` - Get financial report
  - Query params: `startDate`, `endDate`, `driverId`, `groupBy` (day/week/month)
- `GET /api/reports/financial/revenue` - Get revenue breakdown
- `GET /api/reports/financial/commissions` - Get driver commissions
- `GET /api/reports/financial/cash-collections` - Get cash collections
- `GET /api/reports/financial/payroll` - Get payroll summary
- `GET /api/reports/financial/export` - Export report (PDF/Excel)

## Business Rules

### Payment Rules
1. Every job must have a payment method selected
2. Payment status: Unpaid → Pending → Paid
3. Failed payments can be retried
4. Refunds can be processed for paid payments
5. Cash payments require driver confirmation

### Commission Rules
1. Commission percentage applies to all drivers (same rate)
2. Commission calculated as: Job Cost × (Commission % / 100)
3. Commission added to driver's payroll when payment is received
4. Commission percentage can only be changed by SuperAdmin

### Cash Collection Rules
1. Cash amount must equal job cost
2. Cash collected by driver must be confirmed by dispatcher
3. Cash amount deducted from driver's bi-weekly payroll
4. Driver keeps the cash but it offsets payroll

### Payroll Rules
1. Payroll calculated bi-weekly
2. All jobs in period included in calculation
3. Cash collections in period deducted from payroll
4. Payroll status: Draft → Finalized → Paid
5. Once finalized, payroll cannot be modified
6. Only Admin can finalize and mark payroll as paid
